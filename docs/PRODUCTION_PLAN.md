# Production Plan

## 현재 상태

이 앱은 로컬 저장 기반 D-Day MVP에서 iOS 18 잠금화면 위젯과 제어센터 컨트롤을 포함하는 단계로 확장되었습니다.

- SwiftUI 앱 본체
- SwiftData 로컬 저장
- 프로필 저장
- D-Day 생성, 수정, 삭제
- 매년 반복 D-Day 계산
- 대표 D-Day 고정
- WidgetKit 잠금화면 위젯
- iOS 18 제어센터 컨트롤
- App Group 기반 대표 D-Day 스냅샷 공유
- D-Day 알림 설정과 예약 기반
- Privacy manifest 기본 선언

프로덕션 레벨로 가기 위한 우선순위는 다음 순서로 진행합니다.

## 바로 다음 작업

다음 개발 작업은 실제 기기 QA와 스토어 준비를 추천합니다.

이유:

- 잠금화면 위젯, 제어센터 컨트롤, 알림은 시뮬레이터만으로 검증이 부족합니다.
- App Group과 capability 설정은 실제 Apple Developer 계정 상태와 맞아야 합니다.
- 스토어 문구와 스크린샷은 현재 제품 톤을 기준으로 다시 잡아야 합니다.
- 출시 전 마지막 결함은 대부분 실기기 권한, 알림, 위젯 갱신에서 발견됩니다.

작업 시작 기준:

- 현재 앱이 빌드 성공해야 합니다.
- 잠금화면 위젯과 제어센터 컨트롤이 후보 목록에 보여야 합니다.
- 앱 실행 후 대표 D-Day 스냅샷이 정상 표시되어야 합니다.
- 알림 권한 요청과 예약이 실제 기기에서 확인되어야 합니다.

## 주의 사항

- App Group `group.yhb.d-day-app`은 앱 타깃과 Widget Extension 타깃 양쪽에 등록되어야 합니다.
- 위젯과 제어센터는 SwiftData를 직접 읽지 않고 스냅샷만 읽습니다.
- 앱 데이터가 변경될 때마다 `SystemSurfaceSync`로 스냅샷과 위젯/제어센터 reload를 갱신해야 합니다.
- 무거운 빌드/테스트는 CPU 사용량을 확인하면서 필요할 때만 실행합니다.
