# Product Brief

## 한 줄 설명

커플이 둘만의 중요한 날짜를 한눈에 보고, 다가오는 기념일을 놓치지 않도록 도와주는 감성적인 D-Day 앱입니다.

## 대상 사용자

- 연인과 만난 날, 기념일, 생일, 여행일을 자주 확인하고 싶은 사용자
- 위젯이나 알림으로 중요한 날을 놓치고 싶지 않은 사용자
- 복잡한 커플 SNS보다 조용하고 개인적인 기록 앱을 선호하는 사용자

## 핵심 가치

- 중요한 날짜를 빠르게 확인한다.
- 날짜마다 `D-10`, `D-Day`, `D+100`처럼 자연스럽게 표현한다.
- 커플 앱답게 따뜻하지만 과하지 않은 UI를 제공한다.
- 첫 버전은 로컬 데이터 중심으로 안정적으로 시작한다.

## MVP 범위

- 커플 시작일 등록
- 기념일/D-Day 항목 추가, 수정, 삭제
- 홈 화면에서 대표 D-Day와 다가오는 일정 표시
- 생일/기념일을 위한 매년 반복 계산
- 날짜 계산 로직
- 로컬 저장
- 기본 설정 화면

## 다음 버전 후보

- 홈 화면 위젯
- 기념일 알림
- 사진 배경 커스터마이즈
- iCloud/CloudKit 동기화
- 커플 공유 초대
- 잠금 화면 위젯

## 당장 하지 않을 것

- 자체 서버 구축
- 로그인/회원가입
- 채팅, 피드, SNS 기능
- 복잡한 커플 미션 시스템

## 제품 톤

차분하고 따뜻한 앱을 목표로 합니다. 너무 유치하거나 과한 장식보다, 매일 열어도 부담 없는 분위기를 우선합니다.
