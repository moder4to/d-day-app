# Product Brief

## 한 줄 설명

시작일과 주요 일정을 저장하고 남은 날·지난 날을 빠르게 확인하는 D-Day 앱입니다.

## 대상 사용자

- 시작일, 기념일, 생일, 여행일을 자주 확인하고 싶은 사용자
- 위젯이나 알림으로 일정을 놓치고 싶지 않은 사용자
- 잠금화면이나 제어센터에서 D-Day를 빠르게 확인하고 싶은 사용자
- SNS형 기능보다 조용하고 개인적인 기록 앱을 선호하는 사용자

## 핵심 가치

- 저장한 날짜를 빠르게 확인한다.
- 날짜마다 `D-10`, `D-Day`, `D+100`처럼 자연스럽게 표현한다.
- 장식보다 정보 가독성을 우선하는 UI를 제공한다.
- iOS 18 잠금화면과 제어센터에서도 한눈에 읽히는 디자인을 제공한다.
- 첫 버전은 로컬 데이터 중심으로 안정적으로 시작한다.

## MVP 범위

- 시작일 등록
- 일정/D-Day 항목 추가, 수정, 삭제
- 홈 화면에서 대표 D-Day와 다가오는 일정 표시
- 생일/기념일을 위한 매년 반복 계산
- 날짜 계산 로직
- 로컬 저장
- 기본 설정 화면
- 잠금화면 위젯과 iOS 18 제어센터 컨트롤

## 다음 버전 후보

- 홈 화면 위젯
- 위젯/컨트롤 사용자 설정
- 알림 문구와 시간 옵션 고도화
- 사진 배경 커스터마이즈
- iCloud/CloudKit 동기화
- 공유 초대

## 당장 하지 않을 것

- 자체 서버 구축
- 로그인/회원가입
- 채팅, 피드, SNS 기능
- 복잡한 미션 시스템

## 제품 톤

문구는 짧고 구체적으로 씁니다. “우리의 날”, “둘만의”, “감성적인”처럼 의미가 넓거나 과하게 꾸미는 표현은 피하고, 사용자가 할 수 있는 행동과 확인할 정보를 먼저 말합니다. 시각 톤은 디자이너가 이어받기 쉽도록 중립적인 색, 기본 컴포넌트, 명확한 계층을 우선합니다.
