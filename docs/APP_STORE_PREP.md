# App Store Prep

## 앱 정보 초안

- 앱 이름: D-Day
- 앱 부제 후보: 일정까지 남은 날을 빠르게 확인
- 카테고리 후보: Lifestyle
- 최소 iOS 버전: iOS 18.0
- 저장 방식: 기기 내 로컬 저장
- 네트워크 사용: 없음
- 로그인: 없음
- 추적: 없음
- 수집 데이터: 없음

## 한 줄 설명

시작일과 일정을 앱, 잠금화면, 제어센터에서 빠르게 확인하는 D-Day 앱입니다.

## 설명 초안

D-Day는 시작일, 기념일, 생일, 여행일처럼 자주 확인하는 날짜를 관리하는 앱입니다. 저장한 날짜까지 남은 날과 지난 날을 한눈에 확인할 수 있습니다.

iOS 18 잠금화면 위젯과 제어센터 컨트롤을 지원해 앱을 열지 않아도 대표 D-Day를 빠르게 볼 수 있습니다. 모든 데이터는 기기 안에 저장되며 로그인이나 자체 서버 없이 사용할 수 있습니다.

## 주요 기능

- 프로필과 시작일 저장
- 일정 추가, 수정, 삭제
- 매년 반복 기념일 계산
- 대표 D-Day 고정
- 잠금화면 위젯
- iOS 18 제어센터 컨트롤
- D-Day 당일, 하루 전, 7일 전 알림
- 로컬 저장

## 심사 전 체크리스트

- 앱 아이콘 적용
- 실기기에서 앱 실행 확인
- 실기기에서 잠금화면 위젯 노출 확인
- 실기기에서 제어센터 컨트롤 노출 확인
- 실기기에서 알림 권한 요청 확인
- 실기기에서 D-Day 알림 수신 확인
- App Group `group.yhb.d-day-app` 등록 확인
- 앱 타깃 capability 확인
- Widget Extension capability 확인
- Privacy manifest 포함 확인
- 스크린샷 준비

## 스크린샷 후보
