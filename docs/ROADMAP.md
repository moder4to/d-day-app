# Roadmap

## Milestone 0: 프로젝트 기반

- 문서 구조 정리
- SwiftUI/SwiftData 기본 소스 구조 생성
- Mac에서 Xcode 프로젝트 연결
- 첫 시뮬레이터 빌드 성공

## Milestone 1: MVP

- 커플 프로필 저장
- D-Day 항목 생성, 수정, 삭제
- D-Day 항목 목록 표시
- 대표 D-Day 고정
- 매년 반복 일정 계산
- 기본 설정 화면

## Milestone 2: 사용성

- 항목 수정/삭제
- 날짜 정렬과 필터
- 빈 상태 UI 개선
- 입력 검증
- 기본 색상 테마 정리

## Milestone 3: 알림과 위젯

- 기념일 알림
- 홈 화면 위젯
- 잠금 화면 위젯 검토

## Milestone 4: 공유

- iCloud 동기화 검토
- CloudKit 공유 설계
- 커플 초대 플로우
