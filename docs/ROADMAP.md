# Roadmap

## Milestone 0: 프로젝트 기반

- 문서 구조 정리
- SwiftUI/SwiftData 기본 소스 구조 생성
- Mac에서 Xcode 프로젝트 연결
- 첫 시뮬레이터 빌드 성공

## Milestone 1: MVP

- 프로필 저장
- D-Day 항목 생성, 수정, 삭제
- D-Day 항목 목록 표시
- 대표 D-Day 고정
- 매년 반복 일정 계산
- 기본 설정 화면

## Milestone 2: 사용성

- 항목 수정/삭제
- 날짜 정렬과 필터
- 빈 상태 UI 개선
- 입력 검증
- 기본 색상 테마 정리

## Milestone 3: iOS 18 빠른 확인

- 잠금화면/제어센터 디자인 프리뷰
- WidgetKit 잠금화면 위젯
- WidgetKit Control 제어센터 컨트롤
- App Intents 기반 앱 열기/대표 D-Day 액션
- 앱과 확장 간 공유 데이터 스냅샷
- Apple Developer App Group 등록과 실기기 검증

## Milestone 4: 홈 화면 위젯과 알림 고도화

- 홈 화면 위젯
- 알림 문구와 시간 옵션 고도화
- StandBy 표시 검토

## Milestone 5: 공유

- iCloud 동기화 검토
- CloudKit 공유 설계
- 공유 초대 플로우
